# um-agentic-ed

`um-agentic-ed` is a system for building education web apps that are interactive
and dynamically updatable. Apps promote progressive, self-guided learning,
foster team learning, and exploit generative AI to help both educators and learners.

The system was developed at the University of Michigan but is freely usable by 
anyone, with rebranding support.

## um-agentic-ed-parent

This repository, `um-agentic-ed-parent`, is the template to use to start a new 
app repository. Your copy of this template will carry the content that defines 
your app.

## Philosophy: collaborating with AI helps educators and learners

AI is a boon that can help support all phases of educator-learner interactions. 
`um-agentic-ed` is designed to foster that process.

Agentic AI helped us quickly create the `um-agentic-ed` system. It will also help
you quickly create a content outline that AI can "hog in" from your instructions,
including creating interactive widgets limited only by your imagination, that you
can then edit within a running app. Finally, your apps will help learners use 
AI to interact with your content and to learn actively with each other.

`um-agentic-ed` uses modern tools to help you make your content come alive for 
learners!

## Creating a new app from this template

1. Create your own app parent repository by
[copying this template](https://github.com/um-agentic-ed/um-agentic-ed-parent/generate).

2. Make a local clone of your new repository:

```sh
git clone https://github.com/<owner>/<your-app-name>
cd <your-app-name>
```

3. Add the framework submodule required to make your app function:

```sh
git submodule add https://github.com/um-agentic-ed/um-agentic-ed-framework.git src/um-agentic-ed-framework
```

4. Edit files `README.md` (this file) and `AGENTS.md` (in the places marked 
`TODO` only!) to describe the context and content of your new app.

5. From within 
[VS Code](https://code.visualstudio.com/)
or your favorite AI-powered development environment, execute
`/build-app set-app-identity`, OR manually edit file `app.js` to describe
your new app.

6. Double-click `index.html` to open your new app in Chrome (Safari does not 
support in-app editing). You can rename `index.html` to `<your-app-name>.html`
or another name if you'd like.

7. Ctrl-click on the title you gave your app in the upper left corner to toggle
in and out of editing mode. Choose your app root folder and enter an allowed
editor name as prompted.

8. See the 
[um-agentic-ed docs](https://github.com/um-agentic-ed/um-agentic-ed-docs)
for more help using the live app editor, presenter mode, note-taking, and more.

9. Run `/build-app list` to see Framework-supported Agent tasks that can
auto-generate or maintain content you can continue editing.
