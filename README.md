# um-agentic-ed

> **NOTICE**: The `um-agentic-ed` system is in beta development and while usable 
> may not be fully stable. We anticipate a first stable release in late 2026.

`um-agentic-ed` is a system for building interactive educational web apps that 
promote progressive, self-guided team learning and help educators and learners 
exploit generative AI. Apps are serverless and easy to implement with live content 
editing.

The system was developed at the University of Michigan but is freely usable by 
anyone, with rebranding support.

## um-agentic-ed-parent

This repository, `um-agentic-ed-docs`, is an app built in the system that acts
as the system documention as well as complete working app example.

## Collaborating with AI helps educators and learners

AI is a boon that can support all phases of educator-learner interactions. 
`um-agentic-ed` is designed to foster that process.

Agentic AI helped quickly create the `um-agentic-ed` system. It will help you 
quickly create a content outline that AI can "hog in" from your 
instructions—including interactive widgets limited only by your imagination—that 
you can then edit within a running app. Finally, your apps will help learners use 
AI to interact with your content.

`um-agentic-ed` uses AI to help make your content come alive for learners.

## Creating a new app

1. Create your own app parent repository by
[copying the system template](https://github.com/um-agentic-ed/um-agentic-ed-parent/generate).

2. Make a local clone of your new repository:

```sh
git clone --recurse-submodules https://github.com/<owner>/<your-app-name>
cd <your-app-name>
```

3. Check your installation by double-clicking `index.html` in your app 
folder—the template **UM Agentic Ed Parent** app should open.  If not, you likely 
forgot `--recurse-submodules` and must run `git submodule update --init --recursive` 
to clone the required framework submodule.

4. Edit files `README.md` (this file) and `AGENTS.md` (in the places marked 
`TODO` only!) to describe the context and content of your new app.

5. From within 
[VS Code](https://code.visualstudio.com/)
or your favorite AI-powered development environment, manually edit file `app.js` 
to describe your new app, OR execute agent skill `/build-app set-app-identity`.

6. Double-click `index.html` again to open your new app in Chrome (Safari does  
not support in-app editing). Rename `index.html` to `<your-app-name>.html` if 
you'd like.

7. Ctrl/Cmd-click on the title you gave your app in the upper left corner to 
toggle in and out of editing mode. Choose your app root folder and enter an 
allowed editor name as prompted.

8. See the 
[um-agentic-ed docs](https://github.com/um-agentic-ed/um-agentic-ed-docs)
for more help using the live in-app editor, presenter mode, note-taking, and 
more.

9. Run `/build-app list` to see Framework-supported Agent tasks that can
auto-generate or maintain content that you can continue editing.
